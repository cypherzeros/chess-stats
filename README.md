# Chess Stats

A single-file, client-side chess statistics dashboard. Enter a Chess.com or
Lichess username and it fetches your recent games straight from the public API
in your browser and shows record, ratings, openings, time played and more.

- No account, no server, no tracking — everything runs in your browser.
- Open `index.html` locally, or host it anywhere static (GitHub Pages, Netlify…).

Work in progress. Engine-based analysis (blunder review, evals) is planned.
